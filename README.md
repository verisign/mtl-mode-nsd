# NSD Customized for MTL research

This repo contains a customized version of based off the POC NSD from the IETF-121 Hackathon (https://github.com/NLnetLabs/nsd/pull/397). This version implements draft [draft-fregly-dnsop-slh-dsa-mtl-dnssec](https://datatracker.ietf.org/doc/draft-fregly-dnsop-slh-dsa-mtl-dnssec/) and the latest from the MTL mode specification version 08 [draft-harvey-cfrg-mtl-mode](https://datatracker.ietf.org/doc/draft-harvey-cfrg-mtl-mode/).
