# NSD Customized for MTL research

This repo contains a customized version of based off the POC NSD from the IETF-121 Hackathon (https://github.com/NLnetLabs/nsd/pull/397). This version implements draft [draft-kaizer-dnsop-ml-dsa-mtl-dnssec-02](https://datatracker.ietf.org/doc/draft-kaizer-dnsop-ml-dsa-mtl-dnssec/) and the extension [draft-hdong-dnsop-ml-dsa-mtl-dnssec-sigtag-ext-00](https://datatracker.ietf.org/doc/draft-hdong-dnsop-ml-dsa-mtl-dnssec-sigtag-ext/).
